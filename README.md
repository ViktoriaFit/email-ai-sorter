# e# 📧 Email AI Sorter

Программа читает входящие письма через IMAP, отправляет их в AI (Groq) для сортировки и создаёт черновики ответов.

## ✨ Возможности

- 📥 **Чтение почты** — через IMAP (Gmail)
- 🔍 **Извлечение** — отправитель, тема, тело письма
- 🤖 **AI-анализ** — категория (ВАЖНОЕ / ОБЫЧНОЕ / СПАМ)
- ✍️ **Черновики ответов** — для важных писем
- 💾 **Сохранение отчёта** — в `email_report.txt`

## 🛠 Технологии

- **Python 3.12**
- **imaplib** — чтение почты (встроен)
- **email** — парсинг писем (встроен)
- **requests** — HTTP-запросы к Groq
- **Groq API** — AI-анализ
- **VPN + прокси** — обход блокировок

## 📋 Как работает

1. Подключается к Gmail через IMAP.
2. Читает последние 5 писем.
3. Извлекает отправителя, тему, тело.
4. Отправляет всё в AI (Groq).
5. AI сортирует: ВАЖНОЕ / ОБЫЧНОЕ / СПАМ.
6. Для важных — пишет черновик ответа.
7. Сохраняет отчёт в `email_report.txt`.
